# Implementation plan: convergence engine (companion to INTENT_CONVERGENCE_SPEC.md)

Build new package `backend/app/astro/convergence/` beside existing pillars.py/precision.py/classical.py. Existing behaviour and tests stay unchanged; orchestrator switches only when `settings.CONVERGENCE_V2` is on (default off). All new PyJHora calls must sit inside `engine.calc_lock` + `engine.apply(birth.settings)`.

## Layout
types.py (Evidence(rule_id, rule_version, fact_ids, direction +1/-1/0, weight, factors frozenset, interval, text); PillarResult(pillar, value S|M|W|A|NE, evidence, interval, ne_reason); WindowResult(interval, pillars, n, k_evaluated, dependent, promise, result_type, kp, badge, disclaimer); PromiseResult; IntentConfig)
rulepack.py (loads backend/data/rulepack/*.json; entries {rule_id, version, source, conditions, exceptions, status enabled|disabled_verify, verified_by, verified_on, tests}; is_enabled(); disabled rule → NE evidence with ne_reason "rule disabled pending source check"; pytest asserts every rule_id used in code exists in pack and every enabled rule lists tests)
links.py (L1–L6 links, from Lagna weight 1.0 and Moon 0.5; adv(E)=12th from each E) | promise.py (6-factor gate) | dedup.py (factor de-dup P1>P2>P3>P4, n, k_evaluated, result_type, window intersection) | natal.py (template N M1–M4 + optional P1 overlay) | intents.py (loads/validates backend/data/intents/<NN>_<ID>.json; hand-written IntentConfig.from_dict raising on unknown keys, houses outside 1–12, unknown varga, unknown karaka/arudha, unknown hooks; D11/D30 optional → NE) | timing_p1.py | timing_p2.py | timing_p3.py | timing_p4.py | kp.py (own frame, never adds to n; ALL KP rows disabled_verify → "not evaluated") | template_t.py | hooks/{sade_sati,muhurta,compatibility,past_event,rectify,current_dasha,annual,transition,special}.py | specificity.py (CLI gate runner → backend/data/specificity_report.json) | safety.py (per-domain banned phrases + required disclaimers).
Intent JSON fields: intent_id, number, phase, template (T|N|N+T|T_adverse|special), E, E_adverse_explicit, K, V, J, TAJ{houses, muntha_supportive}, TRIG{slow, fast}, KP{houses, negate, status enabled|verify|ne}, hooks[], min_n_for_label, requires_consent, safety_domain, legacy_ids[], forecast_events[].
Factor strings exactly as spec §1.2 (PLANET:VENUS, HOUSE:7, LORD:H7, MOON_NAKSHATRA, LAGNA_SIGN…); P1 and Yogini both carry MOON_NAKSHATRA.
